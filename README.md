# Wanted 통합 채용 대시보드

원티드(Wanted) 채용 공고 데이터를 기반으로, 지원자/채용자 양쪽 입장에서 채용 시장을 진단할 수 있는 대시보드입니다. `PRD.md`의 요구사항을 기준으로 설계했고, 실제 스키마는 `DB.md`에 문서화되어 있습니다.

## 실행 방법

정적 HTML/CSS/JS로만 구성되어 있어 빌드 과정이 없습니다. 모듈 스크립트(`type="module"`)를 사용하므로 `file://`로 직접 열면 CORS 정책에 막힐 수 있어, 로컬 정적 서버로 열어야 합니다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:<포트>/index.html` 접속.

Supabase 접속 정보(`SUPABASE_URL`, anon key)는 `js/config.js`에 하드코딩되어 있습니다. anon key는 읽기 전용 RLS 정책이 걸린 공개 키라 커밋해도 안전합니다(`DB.md` 8장 참고). 원티드 API 키 등 비밀 값은 `.env`에 두고 `.gitignore`로 커밋에서 제외합니다.

## 데이터 소스

- Supabase 프로젝트: `team7-wanted`
- 클라이언트(`js/api.js`)는 오직 Supabase JS 클라이언트(`supabase.from(...)`)로만 데이터에 접근하며, REST 직접 호출이나 SQL 실행은 하지 않습니다.
- PostgREST 기본 1,000행 제한 때문에 `positions`(10,116건) 등 대용량 테이블은 `range()`로 페이지네이션 후 클라이언트 메모리에서 전량을 모읍니다.
- Realtime(`postgres_changes`) 구독으로 원본/집계 테이블 변경 시 자동 재조회합니다.

## 파일 구조

```
index.html          지원자/채용자 입장 전환 + 하위 탭 마크업
css/styles.css       다크 테마 스타일 (reference.webp 톤 참고)
js/config.js         Supabase 클라이언트 초기화
js/api.js            Supabase 데이터 접근 계층 (fetch + realtime)
js/model.js           원본 테이블 조인/비정규화 계층
js/aggregate.js       탭별 파생 지표 계산 (순수 함수)
js/charts.js          차트/게이지/스파크라인 등 순수 DOM/SVG 컴포넌트
js/app.js             상태관리 · 렌더링 · 이벤트 오케스트레이션
```

## 구현 범위 (1차 MVP)

Supabase에 실제로 적재된 테이블(`DB.md` 9장 참고) 위주로 구성했습니다. 로그인/개인화 기능은 이번 범위에서 제외했습니다.

| PRD 화면 | 상태 | 비고 |
|---|---|---|
| 0. 마켓 홈 | ✅ | 직군·지역 분포, 최근 7일 추이, 급등/급감 직군, 추천·마감임박 공고 |
| 1. 취준 로드맵 | ✅ | 직군별 요구 스킬 커버리지, 미보유 스킬, 매칭 공고 |
| 3. 우대조건 필터 | ✅ | 외국인/병역특례/장애인 우대 + 직군·지역·검색 보조 필터 |
| 4. 맞춤 공고 재정렬 | 🚧 준비중 | 로그인/개인 프로필 전제 — 1차 범위 제외 |
| 1. 공고 경쟁력 진단 (채용자) | ✅ | 회사/공고를 검색 + 직무별 그룹으로 선택 → **경쟁 공고 · 보상금 백분위(정확 계산) · 배지 획득 챌린지 · 회사 배지 벤치마킹**(전부 실측 데이터, 선택에 따라 함께 갱신) + 매력 태그 효과 시뮬레이션(선택과 무관한 고정 데모 섹션, 별도 배치) |
| 3. 채용 조건 트렌드 (채용자) | ✅ | 상승/하락 스킬 TOP3, 언급량 랭킹 |

지원자 "기업 건강도 비교", 채용자 "파이프라인 위험 알림"은 필요 데이터(`company_insight_snapshots`, ATS 테이블)를 확보하지 못해 1차 범위에서 탭 자체를 뺐습니다(DB.md 8·9장 참고).

## 알려진 근사치/제약 (화면 내 안내 배너에도 표시)

- 지역 구/시 단위는 주소 텍스트 파싱 기반 근사치 (행정동 좌표 데이터 없음)
- `category_daily_snapshot`/`skill_tag_trend`의 과거 구간은 오늘 실측값에서 역산한 합성 백필값(`is_demo=true`)
- 보상금 백분위·배지 획득 챌린지·회사 배지 벤치마킹·경쟁 공고는 전부 실측 데이터 기반 정확 계산(근사 없음)
- "매력 태그 효과 시뮬레이션"(`tag_effect_stats`)만 ATS 미연동으로 전부 시연용 합성값이며, 화면에서 항상 "데모" 라벨과 함께 다른 카드와 분리해 표시
